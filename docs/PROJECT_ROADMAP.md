# Project Roadmap

This document outlines the high-level roadmap for the Chemistry Companion project.

## Completed Milestones
- **Core Platform**: FastAPI backend and Alpine.js/HTMX frontend integration.
- **AI Infrastructure**: Resilient multi-provider AI pipeline (Groq, DeepSeek, OpenRouter, Gemini).
- **Spectroscopy Module**: NMR and IR prediction workflows.
- **Docking Foundation (Phase 01 & 02)**: Complete protein analysis layer (chains, waters, cofactors, metals, quality assessment, missing residues).

## Current & Upcoming Phases

### Phase 03: Visualization & Intelligent UI
- **Goal**: Wire the AI recommendations to the UI.
- **Tasks**: Show expert recommendations for chains, pockets, waters, and metals directly in the Docking Workspace. Enable user interactions based on AI reasoning.

### Phase 04: Advanced Docking Features
- **Goal**: Expand the docking capabilities.
- **Tasks**:
  - Support for multi-ligand virtual screening.
  - Flexible sidechain selection and preparation.
  - Enhanced pose analysis and visualization.

### Phase 05: Reporting & Export
- **Goal**: Allow users to persist and export their findings.
- **Tasks**:
  - Comprehensive scientific reporting generation (PDF/Excel).
  - Advanced session management and history sharing.
